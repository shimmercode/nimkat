# نیمکت (Nimkat)

پلتفرم آموزش آنلاین و بازارگاه رزرو کلاس خصوصی؛ جست‌وجوی استاد، رزرو کلاس خصوصی و
گروهی، پرداخت و کیف پول، کلاس آنلاین، نیم‌چت، باشگاه مشتریان (نیمکت کلاب) و پنل
شاگرد و استاد. همهٔ صفحات بر اساس بستهٔ طرح‌های فیگما (PDFهای داخل پروژه) پیاده‌سازی
شده‌اند.

## اجرای لوکال (سریع)

نیازمندی: Node.js نسخهٔ ۲۰ یا بالاتر.

- لینوکس/مک: `bash run-local.sh`
- ویندوز: دوبار کلیک روی `run-local.bat`

یا دستی در دو ترمینال:

```bash
# ترمینال ۱ - بک‌اند (API + دیتابیس SQLite)
cd backend
npm install
npm start          # http://localhost:8000

# ترمینال ۲ - فرانت‌اند (React + Vite)
cd frontend
npm install
npm run dev        # http://localhost:5173
```

سایت را روی `http://localhost:5173` باز کنید. درخواست‌های `/api` به‌صورت خودکار
توسط Vite به بک‌اند پراکسی می‌شوند.

### حساب‌های نمونه و ورود OTP

در حالت لوکال پیامک واقعی ارسال نمی‌شود؛ کد OTP در همان صفحهٔ ورود و در لاگ
بک‌اند نمایش داده می‌شود.

| نقش   | شماره موبایل  | مسیر پس از ورود |
| ----- | ------------- | ---------------- |
| شاگرد | 09120000001   | `/panel`         |
| استاد | 09120000002   | `/teacher`       |
| والدین| 09120000003   | `/panel`         |

هر شمارهٔ دیگری هم وارد کنید، حساب تازه با انتخاب نقش ساخته می‌شود.
کد تخفیف نمونه: `MEHR05` (۵٪).

## صفحه‌های پیاده‌سازی‌شده (مطابق PDFها)

- **Home page** — صفحهٔ اصلی کامل با هیرو، اساتید برتر، نوابغ ماه، کلاس‌های گروهی، کلاب، والدین/اساتید، نظرات، FAQ و فرم تماس
- **OTP AND SIGN UP OR LOGIN** — ورود دو مرحله‌ای با کد ۵ رقمی، تایمر ارسال دوباره، سقف ۵ تلاش
- **TEACHERS** — پروفایل استاد با تب‌های معرفی/کلاس‌ها/زمان‌های آزاد/نظرات/پرسش و پاسخ/مدارک/گزارش
- **CLASSES** — جست‌وجو با فیلترها (نوع کلاس، درس، پایه، بستر، ساعت، روز، قیمت، امتیاز) و مرتب‌سازی
- **SINGLE CLASS** — رزرو با تخفیف پلکانی، رزرو دوستانه، کد تخفیف، سرفصل‌ها، قوانین لغو و تست فنی
- **STUDENT PANEL** — داشبورد: کیف پول، حضور، کلاس بعدی، اعلان‌ها، تقویم، گزارش تحصیلی، فایل‌ها
- **TEACHER PANEL** — داشبورد: کلاس‌های امروز، درآمد، سطح استاد، نیم‌پند، درخواست دوره، نظرات، تسویه‌حساب
- **NIMCHAT** — گفت‌وگوی گروهی با اعضا، فایل‌ها، پیام سیستمی و ارسال زندهٔ پیام
- **NIMKAT CLUB** — سطح‌ها، مأموریت‌ها، جوایز قابل دریافت و تاریخچهٔ سکه‌ها
- **SYSTEM DESIGN** — توکن‌های رنگ/فاصله/گردی در `styles/global.css` اعمال شده‌اند

## API (خلاصه)

```
POST /api/auth/otp/request | /api/auth/otp/verify     GET /api/auth/me
GET  /api/teachers | /api/teachers/:id
GET  /api/classes | /api/classes/:id                  POST /api/bookings/quote | /api/bookings
GET  /api/chats | /api/chats/:id                      POST /api/chats/:id/messages
GET  /api/club                                        POST /api/club/rewards/:id/claim
GET  /api/panel/student | /api/panel/teacher          POST /api/wallet/charge
POST /api/teacher/course-requests | /api/teacher/reviews/:id/reply
POST /api/notifications/:id/cancel | /api/questions
```

دیتابیس SQLite است و با اولین اجرا به‌صورت خودکار با دادهٔ نمونهٔ مطابق طرح‌ها
پر می‌شود (`backend/data/nimkat.db`). برای شروع دوباره از صفر، پوشهٔ `backend/data`
را حذف کنید.

## انتشار (Deploy)

فقط خروجی `frontend/dist` روی هاست می‌رود؛ بک‌اند به‌صورت سرویس Node روی سرور
اجرا می‌شود. راهنمای کامل (VPS + Nginx، هاست اشتراکی، دیپلوی خودکار با GitHub
Actions و نکات امنیتی) در [`docs/deploy.md`](docs/deploy.md) است.
