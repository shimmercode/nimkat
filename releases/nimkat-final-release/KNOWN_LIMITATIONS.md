# محدودیت‌های شناخته‌شده و موارد نیازمند زیرساخت خارجی (`KNOWN_LIMITATIONS.md`)

1. **اجرای دیمن Docker و Nginx در محیط سندباکس (`BLOCKED`):**
   فایل‌های `Dockerfile.backend`، `Dockerfile.frontend`، `docker-compose.yml` و `nginx.conf` به‌صورت کامل آماده و بررسی استاتیک شده‌اند، اما به دلیل نبود باینری و دیمن `docker` و `nginx` در محیط سندباکس، اجرای زندهٔ کانتینر در سرور استیجینگ/پروداکشن باید انجام شود.
2. **اجرای Cloud CI در GitHub Actions (`BLOCKED`):**
   فایل `.github/workflows/ci.yml` آماده است، اما به دلیل دستور عدم انجام `git commit` / `git push`، پایپ‌لاین ابری هنوز تریگر نشده است.
3. **سرویس‌های تجاری خارجی (`BLOCKED_EXTERNAL`):**
   درگاه پرداخت بانکی (شاپرک) و پنل پیامک (SMS OTP) در نسخهٔ فعلی به‌صورت شبیه‌سازی‌شده (Simulated) کار می‌کنند و نیازمند کلیدهای تجاری کارفرما در محیط پروداکشن هستند.
