# نیمکت (Nimkat)

پلتفرم آموزش آنلاین و بازارگاه رزرو کلاس خصوصی؛ ارتباط دانش‌آموزان با استادها برای
جست‌وجو، انتخاب استاد، رزرو کلاس، پرداخت و شرکت در کلاس آنلاین.

## امکانات اصلی

- جست‌وجو و فیلتر پیشرفتهٔ استادها
- پیشنهاد هوشمند استاد متناسب با نیاز دانش‌آموز
- رزرو کلاس خصوصی و گروهی با نقشهٔ صندلی، پرداخت و کیف پول
- کلاس آنلاین و سیستم پرسش‌وپاسخ (نیم‌چت) پیش و بعد از رزرو
- آزمون تعیین سطح و گزارش پیشرفت تحصیلی
- پنل دانش‌آموز، استاد، والدین، اپراتور و مدیر
- تیکت، اعلان، امتیازدهی، احراز هویت استاد و نیمکت کلاب
- مجلهٔ نیمکت برای محتوای آموزشی و ورودی گوگل

## ساختار مخزن

```
nimkat/
├── frontend/          # React + Vite (رابط کاربری سایت)
│   ├── index.html     # صفحهٔ RTL فارسی
│   ├── src/
│   │   ├── components/   # بخش‌های صفحهٔ اصلی
│   │   ├── styles/       # استایل سراسری و توکن‌های رنگ
│   │   ├── utils/        # ابزارهای اعداد فارسی
│   │   └── assets/       # تصاویر
│   └── vite.config.js
├── docs/
│   └── deploy.md      # راهنمای انتشار روی سرور
└── .github/workflows/ci.yml   # بیلد و بررسی خودکار با هر push
```

بک‌اند (Laravel + MySQL) هنوز به مخزن اضافه نشده و در مرحلهٔ بعدی به‌صورت پوشهٔ
جدید `backend/` اضافه می‌شود؛ فرانت‌اند فعلاً با دادهٔ نمونه کار می‌کند.

## اجرای محلی (لوکال)

نیازمندی: Node.js نسخهٔ ۲۰ به بالا.

```bash
cd frontend
npm install
npm run dev        # سرور توسعه: http://localhost:5173
```

تست نسخهٔ انتشار:

```bash
npm run build      # خروجی در پوشهٔ dist
npm run preview    # پیش‌نمایش نسخهٔ بیلدشده
```

## اسکریپت‌ها

| دستور         | کار                                  |
| ------------- | ------------------------------------ |
| `npm run dev`     | سرور توسعه با HMR                |
| `npm run build`   | بیلد بهینهٔ انتشار در `dist`   |
| `npm run preview` | اجرای محلی خروجی بیلد            |

## انتشار (Deploy)

خلاصه: فقط خروجی `dist` روی هاست می‌رود، نه `node_modules` و نه سورس.
راهنمای کامل سه روش (VPS با Nginx، هاست اشتراکی cPanel، و دیپلوی خودکار با
GitHub Actions) در [`docs/deploy.md`](docs/deploy.md) آمده است.

با هر push به شاخهٔ اصلی، workflow فایل `ci.yml` فرانت‌اند را بیلد می‌کند تا
خرابی‌ها قبل از انتشار دیده شوند.
