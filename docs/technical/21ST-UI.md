# به‌روزرسانی رابط با کامپوننت‌های منتخب 21st

کاتالوگ عمومی و دسته‌های منو، CTA و فوتر بررسی شدند. کتابخانهٔ Tailark انتخاب
شد؛ کد چهار بلوک مرتبط مستقیماً از مخزن upstream با commit ثابت دریافت شد،
نه اینکه کل کاتالوگ چند هزارکامپوننتی نصب شود. سند منبع/مجوز/تطبیق‌ها:
`frontend/src/components/ui/twenty-first/SOURCES.md` و `manifest.json`.

## محل استفاده
- Header مشترک همهٔ صفحات عمومی: منوی شناور، مگامنوی کلاس‌ها، active state،
  لینک‌های فیلتر واقعی و پنل موبایل Radix با focus trap و Escape.
- HeroBlock ادیتور و Home fallback هر دو HeroFrame یکسان را import می‌کنند.
  عکس‌ها و جست‌وجوی عملیاتی قبلی حفظ شده‌اند؛ صحنهٔ لایه‌ای و نشان بالای عنوان
  اضافه شده است. متن/لینک نشان در ادیتور قابل تغییر است.
- CtaBandBlock ادیتور و Home fallback از ActionPanel مشترک استفاده می‌کنند؛
  عنوان/شرح/لینک‌ها حفظ شده، نشان و نمایش مراحل قابل تنظیم است.
- Footer مشترک: FooterGrid، لینک‌های درست مقاطع، RSS/sitemap، بازکردن پشتیبانی
  و بازگشت واقعی به بالای صفحه. لینک‌های `#`، شماره و مجوزهای نمایشی قدیمی
  دیگر نمایش داده نمی‌شوند؛ آدرس شبکه‌های اجتماعی/مجوز واقعی اختراع نشده است.

## قیود طراحی
رنگ‌های پایهٔ global.css تغییر نکرده‌اند. CSS جدید از متغیرهای همان پالت،
رادیوس‌ها و یکان‌بخ میزبانی‌شدهٔ پروژه استفاده می‌کند. متن دکمهٔ نارنجی N900
است. CSS در `styles/community.css` نام‌گذاری nk-* دارد تا پنل‌ها، باکس رزرو،
مجله و چت پذیرفته‌شده تغییر ناخواسته نکنند. Radix دو وابستگی عملیاتی جدید است؛
لایبرری جداگانهٔ انیمیشن یا فونت خارجی نصب نشده است.

## آزمون
`tests/e2e/community-ui.spec.ts` پوشش می‌دهد: منوی دسکتاپ با کیبورد و فیلتر
گروهی واقعی، پنل موبایل در عرض ۳۲۰/۳۹۰ و landscape، مهار و بازگردانی فوکوس،
رنگ و فونت محاسبه‌شده در عرض‌های ۳۲۰ تا ۱۹۲۰، عملکرد CTA/پشتیبانی/بازگشت به
بالا، نبود لینک خالی در فوتر و reduced-motion. تست‌های ورود و ادیتور قبلی نیز
باید همراه این سه تست اجرا شوند؛ تست را فقط روی DB جدا اجرا کنید.

نتیجهٔ اجرای نهایی روی build تولیدی: ۳۳/۳۳ مرورگر Chromium، ۱۱/۱۱ واحد فرانت‌اند،
۳۱/۳۱ بک‌اند، TypeScript و diff check موفق. پیش‌نمایش نهایی از دادهٔ عادی و بدون
SITE_URL آزمایشی اجرا شده است. این نتیجه ادعای آزمون Safari/Firefox نیست.
