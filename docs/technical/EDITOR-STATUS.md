# ویرایشگر بصری — ۲۰ اکتبر ۲۰۲۶

اولویت طبق درخواست جدید تغییر کرد: این مرحله مخصوص ویرایشگر است؛ تکمیل زیرساخت/خدمات باقی‌ماندهٔ تجارت به بعد از آن منتقل شد.

## ورود و استفاده

- مدیر سایت: `/editor/home`؛ دکمهٔ «ویرایش همین صفحه» در سربرگ عمومی، و لینک ویرایشگر در تنظیمات مدیریت.
- انتخاب صفحه: خانه، کلاس‌ها، قالب استاد، قالب جزئیات کلاس، کلاب، چیدمان مجله و قالب پیرامون مقاله؛ صفحات ذخیره‌شده و نمونه‌های `teacher-ID` و `class-ID` نیز در فهرست ظاهر می‌شوند.
- صفحهٔ سفارشی: «صفحهٔ جدید»، عنوان و slug انگلیسی، ساخت پیش‌نویس؛ بعد از انتشار در `/p/slug` نمایش داده می‌شود. تا انتشار، صفحه عمومی ساخته نمی‌شود.
- لایه‌ها: افزودن، کپی، حذف، بالا/پایین و کشیدن. Shift هنگام رهاکردن یعنی قبل از مقصد؛ Alt یعنی داخل کانتینر. انتقال به فرزند خود یا داخل بلوک غیرکانتینر مسدود است.
- انتخاب کانتینر و افزودن بلوک، آن را فرزند کانتینر می‌کند؛ انتخاب بلوک معمولی، بلوک جدید را بعد از آن قرار می‌دهد.
- کانتینر Flex/Grid: جهت، شکستن ردیف، ستون‌های شبکه، تراز و فاصله؛ تمام تنظیمات در هر breakpoint جدا هستند.
- عنوان/متن عمومی: ویرایش از پنل یا دوبار کلیک در بوم؛ Enter ثبت، Shift+Enter خط جدید، Escape انصراف. چسباندن در این حالت متن ساده است.
- تنظیمات استایل: فاصلهٔ چهار جهت، عرض/ارتفاع، قلم، کادر، شعاع، سایه، تراز و رنگ‌های برند؛ فونت عمومی Yekan Bakh تغییر نمی‌کند. اندازهٔ قلم کمتر از ۱۲ در ذخیره پذیرفته نمی‌شود.
- نمایش/عدم نمایش و پاک‌کردن تنظیمات هر دستگاه؛ استایل‌های موبایل از تبلت و دسکتاپ ارث می‌برند. CSS واکنش‌گرای واقعی در HTML عمومی نیز تولید می‌شود؛ نیازمند انتظار برای اجرای resize در مرورگر نیست.
- بوم iframe با عرض واقعی ۱۲۸۰/۷۶۸/۳۷۵؛ media queryها در viewport خود بوم اجرا می‌شوند. این شبیه‌ساز سخت‌افزار، شبکه یا تمام APIهای موبایل نیست. بخش‌های پنل در نمایشگر باریک با تب بوم/لایه‌ها/تنظیمات قابل دسترسی‌اند.

## ذخیره و انتشار

پیش‌نویس، نسخهٔ منتشرشده، تاریخچه و قالب‌ها جدا می‌مانند. ذخیره، انتشار، خروج از انتشار و بازگردانی تاریخچه مسیر API واقعی دارند. بازگردانی تاریخچه، پیش‌نویس را تغییر می‌دهد، نه نسخهٔ زنده را تا انتشار بعدی.

ویرایشگر revision صفحه را در ذخیره/انتشار/بازگردانی می‌فرستد. تغییر هم‌زمان صفحه، پاسخ ۴۰۹ می‌دهد و متن مدیر دوم بی‌صدا روی مدیر اول نوشته نمی‌شود. API قدیمی بدون revision برای سازگاری با مصرف‌کنندگان قبلی هنوز پذیرفته می‌شود؛ همهٔ مشتریان قدیمی گواه حفاظت تعارض نیستند.

هنگام درخواست ذخیره، snapshot همان لحظه ارسال می‌شود؛ ویرایش‌های تازه‌تر حین درخواست با پاسخ قدیمی «تمیز» علامت نمی‌خورند. انتشار دوباره‌کلیک با قفل درخواست رابط محافظت شده است.

تغییرات ذخیره‌نشده پس از مکث کوتاه در localStorage با کلید مختص مدیر و صفحه نگه داشته می‌شوند. پس از reload، بازیابی فقط با انتخاب مدیر انجام می‌شود؛ هیچ بازیابی/قالبی خودکار منتشر نمی‌شود. قبل از ترک مرورگر هشدار وجود دارد. این ذخیرهٔ محلی جای backup سرور نیست؛ روی دستگاه مشترک باید احتیاط شود.

Ctrl/Cmd+S ذخیره است. Undo/Redo سراسری وقتی تمرکز داخل ورودی متنی است، تاریخچهٔ native تایپ را نمی‌رباید. قالب اعمال‌شده به‌عنوان تغییر ذخیره‌نشده علامت می‌خورد. مودال‌ها نقش dialog، Escape، چرخهٔ Tab و بازگشت تمرکز دارند.

## رسانه

کتابخانه و بارگذاری PNG/JPEG/WebP فقط برای مدیر است. حداکثر ورودی پنج مگابایت، decode محدود به ۲۴ میلیون پیکسل، خروجی حداکثر ۲۴۰۰×۲۴۰۰، WebP بازکدگذاری‌شده و بدون EXIF است. امضای فایل بررسی می‌شود؛ SVG حتی با MIME جعلی پذیرفته نمی‌شود. فایل‌های همسان deduplicate می‌شوند. بودجهٔ محلی ۱۲۸ مگابایت است.

تصاویر کتابخانه **عمومی و قابل انتشارند**؛ این مسیر برای مدارک هویتی، فایل شاگرد یا پیوست خصوصی نیست. API خواندن تصویر کش immutable دارد. داده در `<NIMKAT_DATA_DIR>/editor-media` ذخیره می‌شود و باید همراه دیتابیس backup شود. object storage/CDN، حذف امن با بررسی تمام نسخه‌های ارجاع‌دهنده، و صفحه‌بندی کامل کتابخانه در رابط این مرحله تکمیل نشده‌اند؛ API فهرست offset دارد و رابط فعلی ۵۰ تصویر اخیر را نشان می‌دهد.

## محدوده و محافظت از عملیات

- قیمت، موجودی کلاس، کیف پول، شناسهٔ اشخاص و منطق رزرو از API می‌آیند؛ فیلد مالی قابل جعل در inspector ندارند.
- در بوم، کلیک برای انتخاب بلوک است و مسیر خرید/پاداش/ناوبری واقعی اجرا نمی‌شود؛ widgetهای پویا نیز inert هستند.
- HTML عنوان و متن فقط قالب‌بندی محدود و رنگ‌های highlight مجاز دارد؛ تگ اجرایی، event handler، CSS دلخواه و iframe وارد innerHTML نمی‌شوند. URL رسانه و لینک اجرایی، کلید prototype و CSS دارای URL/تزریق در نوشتن سرور رد می‌شوند.
- مجله/مقاله، محتوای واقعی SSR و SEO تحریریه را در slot پویا نگه می‌دارد؛ بلوک‌های پیرامون آن قابل چیدمان‌اند. متن مقاله همچنان از تحریریه مدیریت می‌شود. این به معنی تبدیل همهٔ اجزای داخل مقاله به widget آزاد نیست.
- سربرگ و پابرگ عمومی فعلی، فرم ورود/OTP و صفحات مالی حساس، HTML آزاد قابل جایگزینی نیستند. این مرحله **ادعای برابری کامل با تمام امکانات Elementor Pro**، ویرایش تک‌تک DOMهای داخلی widgetهای تجاری، theme builder کامل سربرگ/پابرگ یا همکاری هم‌زمان زنده ندارد.
